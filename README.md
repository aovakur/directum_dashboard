# Directum Dashboard

Интерактивный дашборд для мониторинга просроченных задач из **Directum** и других интегрированных систем.

## Описание

Приложение визуализирует данные о просроченных задачах, позволяя быстро оценить общую картину по организации, найти проблемные подразделения и сотрудников с наибольшим количеством просрочек.

## Возможности

- **Общая статистика** — общее количество просроченных задач, сотрудников, среднее значение, подразделение с максимальной просрочкой
- **Дерево подразделений** — навигация по департаментам и отделам с иерархией
- **Карточки сотрудников** — количество просроченных задач с визуальной шкалой (жёлтый / красный)
- **Фильтрация и поиск** — поиск по ФИО, отделу, подразделению, задачам
- **Детализация задач** — просмотр полного списка просроченных задач сотрудника или куратора (ID, тема, исполнитель, инициатор, сроки, ссылка на задачу)
- **Рейтинги** — топ-20 сотрудников, сотрудник с максимальной просрочкой, подразделение с максимальной просрочкой
- **Кураторы** — просмотр задач по кураторам с отображением организационной иерархии
- **Экспорт** — сохранение дашборда в PNG-скриншот

## Структура данных

Данные о задачах и подразделениях загружаются из `data.json`:

- **departments** — структура подразделений (название, короткое имя, иконка, руководство, сотрудники)
- **tasks** — массив задач (ID, тема, исполнитель, инициатор, куратор, сроки, подразделение, ссылка)
